# 📝 TODO App

A simple and modern task management web application built with **Python and Django**.

This project was created to practice Django fundamentals and build a complete web application with authentication, CRUD operations, database integration, and interactive frontend features.

## ✨ Features

* 🔐 User registration and authentication
* ➕ Create tasks
* ✏️ Edit tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔎 Search tasks
* 🌙 Dark / Light theme
* 💾 Persistent theme preference using `localStorage`
* 👤 User-specific tasks
* 📱 Clean and responsive interface

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/zekaXZX/TODO_app.git
cd TODO_app
```

### 2. Create and activate a virtual environment

**Linux / macOS**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Apply migrations

```bash
python manage.py migrate
```

### 5. Run the development server

```bash
python manage.py runserver
```

Then open:

```text
http://127.0.0.1:8000/
```
